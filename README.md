# Pusula YDS

YDS'ye hazırlık uygulaması: kelime kartları, soru tipleri, okuma parçaları, deneme sınavları ve sınav stratejisi.

- Uygulama: `index.html`
- Gizlilik Politikası: `gizlilik.html`
- Kullanım Koşulları: `kosullar.html`
- İçerik: `data/` klasörü (kelimeler, sorular, okuma metinleri, dilbilgisi)
- Telaffuz kayıtları: `audio/` klasörü

Yeni sürüm yayınlarken `sw.js` içindeki `SURUM` değerini artırın; böylece kullanıcıların telefonundaki çevrimdışı kopya da yenilenir.
